### Prism Motion

![language-kotlin](https://img.shields.io/badge/language-kotlin-orange.svg) [![license-MIT](https://img.shields.io/badge/license-MIT-blue)](<LICENSE>)

### 介绍

`Prism Motion` 是基于 `Kotlin` 编写的 Android / JVM 动画播放库，通过统一的 `.prism` 资源格式与 Compose API 接入 KAP 纹理动画和 VAP 视频动画，提供一致的播放控制、资源管理与完整性校验，并配套原生 CLI 完成动画打包、探测与检查。
